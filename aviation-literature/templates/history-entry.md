# 历史对话 · 会话区块骨架

复制下面整块，追加到 `对话记录/历史对话.md` 末尾。**只追加，不改写、不删除既有内容。**

```markdown
---

## [YYYY-MM-DD HH:mm] 会话主题（如：工艺审查文献检索）

- **需求**：（用户原话或概述）
- **动作**：（用了哪些检索词，跑了哪些脚本与命令）
- **结果**：（给出的文献清单或回答要点）
- **入库**：（逐条结果：API 建立 Key=… / 已存入 skill-import 待导入 / 跳过（馆藏已有））
- **待办**：（用户待确认的事项、建议补充检索的方向）
```

## 填写要求

| 字段 | 要求 |
|---|---|
| 时间 | 用当日真实时间，格式 `YYYY-MM-DD HH:mm`，放在二级标题里 |
| 需求 | 优先抄用户原话；用户没明说时写你推断出的意图，并标注「推断」 |
| 动作 | 写清具体检索词与执行过的命令，便于换工具后复现 |
| 结果 | 只写结论与清单要点，不复制完整输出 |
| 入库 | 逐条如实写。跳过、失败、待人工导入都要写出来，不许含糊 |
| 待办 | 没有就写「无」，不要省略该行 |
